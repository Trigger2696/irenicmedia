# Requirements

## v1 Requirements

### Layout & Structure (LAYOUT)

- [ ] **LAYOUT-01**: Site has responsive single-page layout that works on mobile, tablet, and desktop
- [ ] **LAYOUT-02**: Header displays logo and navigation links that scroll to page sections
- [ ] **LAYOUT-03**: Footer displays service links, company links, social icons, and copyright
- [ ] **LAYOUT-04**: Navigation links smooth-scroll to their target sections
- [ ] **LAYOUT-05**: Dark/light theme toggle matches marko template behavior

### Hero Section (HERO)

- [ ] **HERO-01**: Hero displays YouTube video as fullscreen background (muted, looped, autoplay)
- [ ] **HERO-02**: Hero displays main headline: "Growth without chaos. Strategy without noise."
- [ ] **HERO-03**: Hero displays subheadline describing Irenic Media's value proposition
- [ ] **HERO-04**: Hero displays two CTA buttons: "Start Your Journey" and "Explore Services"
- [ ] **HERO-05**: Hero displays stats: 50+ Projects, 95% Client Retention, 3x Average ROI

### Services Section (SERV)

- [ ] **SERV-01**: Services section displays 6 service cards in responsive grid
- [ ] **SERV-02**: Each service card shows icon, title, and description
- [ ] **SERV-03**: Services: Social Media Marketing, SEO, Performance Marketing, Influencer Campaigns, Mobile App Dev, Custom Software Dev
- [ ] **SERV-04**: Service cards animate on scroll (fade-in)

### About Section (ABOUT)

- [ ] **ABOUT-01**: About section displays founder story (Raj Shah & Ruchika Chandel)
- [ ] **ABOUT-02**: About section displays company values: Strategy First, Creative Intent, Long-term Growth
- [ ] **ABOUT-03**: About uses two-column layout (story left, values right on desktop)

### Why Us Section (WHY)

- [ ] **WHY-01**: Why Us section displays 4 differentiator cards
- [ ] **WHY-02**: Differentiators: Strategy Before Execution, Data-Driven Decisions, Transparent Partnership, Agile & Adaptive
- [ ] **WHY-03**: Each card shows icon, title, description, and stat

### Testimonials Section (TEST)

- [ ] **TEST-01**: Testimonials section displays 3-4 client testimonials
- [ ] **TEST-02**: Each testimonial shows client photo, name, company, role, and review text
- [ ] **TEST-03**: Testimonials match marko template card styling

### Case Studies Section (CASE)

- [ ] **CASE-01**: Case Studies section displays 3-4 project showcases
- [ ] **CASE-02**: Each case study shows project image, title, category, and key results
- [ ] **CASE-03**: Case studies match marko template card styling

### Pricing Section (PRICE)

- [ ] **PRICE-01**: Pricing section displays 3 service tiers (Starter, Growth, Enterprise)
- [ ] **PRICE-02**: Each tier shows price, feature list, and CTA button
- [ ] **PRICE-03**: Pricing matches marko template styling with highlighted "popular" tier

### Contact Section (CONT)

- [ ] **CONT-01**: Contact section displays form with name, email, company, message fields
- [ ] **CONT-02**: Form validates required fields and email format before submission
- [ ] **CONT-03**: Contact info displays: hello@irenicmedia.com, +91 98765 43210, Mumbai, India
- [ ] **CONT-04**: Form shows success message after submission

### Visual Design (VIS)

- [ ] **VIS-01**: Site matches marko template CSS styling exactly
- [ ] **VIS-02**: Site uses marko template color scheme and typography
- [ ] **VIS-03**: Site uses animate.css or equivalent scroll animations
- [ ] **VIS-04**: Site uses Font Awesome icons matching template
- [ ] **VIS-05**: All sections animate on scroll (fadeIn, slideUp patterns)

## v2 Requirements (Deferred)

- Blog section with posts — no content available
- Individual service pages — keeping single-page for v1
- Newsletter signup with backend — no email service
- Client logo carousel — no logos provided
- Map integration — unnecessary complexity

---

## Out of Scope

- **Multi-page routing** — single-page is cleaner for a service agency
- **CMS integration** — static content is sufficient
- **Authentication** — not needed for marketing site
- **E-commerce/payments** — not a sales platform
- **Backend API** — contact form will be frontend-only for now
