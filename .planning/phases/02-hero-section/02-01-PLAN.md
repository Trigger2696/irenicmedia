Create a custom hook that animates a number from 0 to a target value over a specified duration.

Create file `hooks/useCountUp.ts`:
- Export function `useCountUp(target: number, duration: number, start: boolean): number`
- Use useState for current count value
- Use useEffect triggered by `start` boolean
- Calculate step increment: ~60 steps over duration
- Use setInterval to increment count
- Clear interval when reaching target or on cleanup
- Return current count value

Parameters:
- target: Final number to count up to
- duration: Time in milliseconds (default 2000)
- start: Boolean that triggers the animation when true

The hook should NOT start automatically - it waits for `start` to become true (controlled by Intersection Observer).

Create a client component that embeds a YouTube video as a fullscreen background.

Create directory `components/Hero/` and file `YouTubeBackground.tsx`:

1. Add 'use client' directive (required for DOM manipulation)

2. Declare global types for YouTube IFrame API:
```typescript
declare global {
  interface Window {
    YT: typeof YT
    onYouTubeIframeAPIReady: () => void
  }
}
```

3. Props interface:
```typescript
interface YouTubeBackgroundProps {
  videoId: string
}
```

4. Component implementation:
- useRef for player instance and container div
- useEffect to load YouTube IFrame API script dynamically
- Check if window.YT already exists before loading script
- Create player in onYouTubeIframeAPIReady callback

5. Player configuration (CRITICAL for background video):
```typescript
playerVars: {
  autoplay: 1,
  controls: 0,
  mute: 1,
  loop: 1,
  playlist: videoId,  // REQUIRED for loop to work
  rel: 0,
  disablekb: 1,
  iv_load_policy: 3,
  playsinline: 1,
  enablejsapi: 1,
  origin: typeof window !== 'undefined' ? window.location.origin : ''
}
```

6. Resize handler for cover behavior:
- Get container dimensions
- Calculate video dimensions to maintain 16:9 while covering container
- Apply width/height to iframe via getIframe().style

7. Event handlers:
- onReady: call playVideo() and resizePlayer()
- onStateChange: if ENDED, call playVideo() (backup for loop)

8. Render structure:
```tsx
<div ref={containerRef} className="absolute inset-0 overflow-hidden">
  <div
    id="youtube-background"
    className="absolute top-1/2 left-1/2 -translate-x-1/2 -translate-y-1/2 pointer-events-none"
  />
</div>
```

9. Cleanup: Remove resize event listener on unmount

Use placeholder video ID "P68V3iH4TeE" (from marko template) for testing.
